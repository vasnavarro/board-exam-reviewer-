# PassBoard ✨ Board Exam Companion & Reviewer

A modern, responsive, high-aesthetic board exam reviewer web application built with love for board exam reviewees. Designed for seamless practice on laptops, tablets, and phones.

---

## 🌟 Key Features

* 💖 **Personalized Study Dashboard**: Dedicated motivational notes, countdown clock to board exam day, streak tracker, and daily inspirational quotes.
* 📝 **Timed Mock Exam**: Realistic board exam simulation with configurable question limits, countdown timer, question palette jumper, flag for review, and instant diagnostics upon submission.
* 🗂️ **3D Interactive Flashcards**: Active recall flip cards with spaced repetition self-rating (Again, Hard, Good, Easy) and deck shuffle.
* ⚡ **Instant Practice Drill**: Immediate feedback with in-depth rationales, option breakdowns, and key takeaway mnemonics.
* 🎯 **Weakness Focus Mode**: Automatically isolates missed exam questions and bookmarked topics to achieve 100% mastery.
* 📚 **Customizable Question Bank**: Easily add, edit, search, and delete questions. Includes full **JSON Export & Import** to load custom exam syllabi.
* 📌 **Built-in Cheat Sheet & Study Notes**: Auto-saving notebook pre-loaded with high-yield board exam frameworks (ABCs, ROME rule, RACE protocol, dosage formulas).
* 🔊 **Synthesized Web Audio Effects**: Pleasant chimes on correct answers and victory fanfares (with mute toggle, no external audio files required!).
* 💾 **100% Client-Side Persistence**: All progress, custom questions, exam date, and scores persist automatically in `localStorage`.

## 🚀 Getting Started

### 1. Run Locally
```bash
cd board-exam-reviewer
npm install
npm run dev
```

### 2. Build for Production
```bash
npm run build
```

## 🌐 Free 1-Click Hosting Options

Since PassBoard is a static single-page application (SPA), you can host it for free so she can practice anywhere:
* **Vercel**: Connect your GitHub repository to [Vercel](https://vercel.com/) for automatic deploys.
* **GitHub Pages**: Build and deploy to GitHub Pages with GitHub Actions.
* **Netlify**: Drag-and-drop the `dist` folder or connect via GitHub on [Netlify](https://netlify.com/).
